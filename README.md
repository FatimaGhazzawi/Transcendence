# Connect Four Arena

A browser-based competitive Connect Four site, built for 42's `ft_transcendence`.

> 🚧 Work in progress. Planning and scaffolding are underway.

## Planned features

- Accounts: email/password, 42 OAuth, two-factor authentication
- Live online 1v1 matches with reconnection
- AI opponent
- Spectator mode
- Single-elimination tournaments
- Stats, match history and leaderboard
- i18n (EN / FR / AR with RTL)

## Planned stack

- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Fastify + TypeScript, Socket.IO
- **Database:** SQLite via Prisma
- **Deployment:** Nginx + Docker Compose
